# 写経ロードマップ（機能をひとつずつ積む）

更新日: 2026-08-08
方針: **1ステップ＝1機能。写経したら必ず動かして、動いてから次へ進む。**

---

## なぜこの順番か

「音が鳴る」から始めます。理由は、**iOS Safari で一番地雷が多いのが音**だからです。
ここが動かなければ企画ごと成立しません。逆にここさえ突破すれば、残りは普通の
Web アプリ開発になります。**危ない所から先に潰す**という順序です。

カメラや OCR は後半に置いていますが、これは難しいからではなく、
「鳴らない目覚まし」には価値が無いのに対し「解除できない目覚まし」は
最悪スマホを再起動すれば済むからです。優先度の問題です。

## Step 0: プロジェクト作成

```bash
cd C:\project\alart-task
npm create vite@latest app -- --template react-ts
cd app
npm install
npm run dev
```

`app/` の下にできます。`docs/` と分けておくと見通しが良いです。

### 写経のお供（強く推奨）

`npm run dev` は**型チェックをしません**。写し間違えても画面は動いてしまい、
その行を実行して初めて壊れます。別のターミナルをもう一枚開いて、
これを流しっぱなしにしてください。

```bash
cd C:\project\alart-task\app
npm run typecheck     # = tsc -b --watch
```

写し間違えた瞬間に赤が出ます。写経の相棒です。

> `npm run build` の側には最初から `tsc -b` が入っているので、
> ビルド時には必ず型チェックが走ります。上のは「書いている最中に気づくため」のものです。

### 実機で試すための準備

音も Wake Lock もカメラも、**PC のブラウザと iPhone では挙動が違います**。
最初から iPhone で確認できるようにしておきます。

```bash
npm run dev:host      # = vite --host
```

表示される `http://192.168.x.x:5173` に iPhone の Safari からアクセスします
（PC と iPhone が同じ Wi-Fi にいること）。

> **注意**: カメラ（Step 5 以降）は HTTPS でないと動きません。
> `http://192.168.x.x` では拒否されます。
> **Step 1〜4 は http のままで大丈夫**です。音と Wake Lock は http でも動きます。
> Step 5 以降は、次の Step 0.5 で用意するデプロイ版（HTTPS）で確認します。

## Step 0.5: デプロイの配線（PC を消せるようにする）

### なぜ最初にやるのか

`npm run dev` は **自分の PC がサーバーになって iPhone に配信している**状態です。
つまり PC を落とすと使えません。目覚ましとしては論外です。

一度ホスティングに上げてしまえば、配信するのは向こうのサーバーなので
**PC の電源は完全に無関係**になります。夜は PC を落として構いません。
さらに HTTPS が付いてくるので、Step 5 のカメラ問題も同時に片付きます。

配線は最初の一度きりで、以後は `git push` するだけで反映されます。

### 手順（Cloudflare Pages / 無料）

1. https://dash.cloudflare.com → Workers & Pages → Create → Pages
2. GitHub の `kkawashun1121-dev/alart-task` を連携
3. ビルド設定を次のようにする

| 項目 | 値 |
|---|---|
| Framework preset | Vite |
| Build command | `npm run build` |
| Build output directory | `dist` |
| **Root directory** | `app` ← アプリを `app/` に作ったので必須 |

4. デプロイ完了後、`https://alart-task.pages.dev` のような URL が発行される
5. iPhone の Safari でその URL を開く

Vercel でも同じことができます。好みで構いません。

### 使い分け

| やること | 使うもの | PC | ネット |
|---|---|---|---|
| コードを書いて即確認 | `npm run dev -- --host` | 必要 | 同じWi-Fi |
| 実際に朝まで使う | デプロイ版の URL | **不要** | 必要 |
| Step 10 完了後 | ホーム画面のアイコン | **不要** | **不要** |

> **Step 4 まで写経できたら、push して実戦投入してみてください。**
> 作り込む前に「本当に自分に効くか」を確かめるのが、この企画で一番大事な検証です。

## 進め方のルール

1. **1ステップ写したら必ず iPhone で動かす。** まとめて写さない
2. 動かなかったら次に進まない。ここで潰しておかないと原因の切り分けが難しくなる
3. コメントも一緒に写す。3ヶ月後の自分が読む
4. 変数名や定数は自由に変えてよい。**丸写しより、少し変えて動かす方が身に付く**
